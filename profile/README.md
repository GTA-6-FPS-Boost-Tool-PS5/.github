## 🔌 How PS5 Connection Works

The configuration workflow uses Sony's supported Remote Play application.

**Connection workflow:**

1. Prepare the PlayStation 5.
2. Enable Remote Play in console settings.
3. Install PS Remote Play on Windows.
4. Authenticate with your PlayStation account.
5. Connect to your console.
6. Review available system and display settings.

PS Remote Play provides authorized console access. It does not expose GPU clock controls or override a game's internal FPS limit.

## 🛠️ GTA VI Performance Configuration

### Step 1 — Game Presets

Navigate to:

Settings > Saved Data and Game/App Settings > Game Presets

Choose a preferred performance preset.

The game must support the selected mode for it to affect gameplay.

### Step 2 — Video Output

Navigate to:

Settings > Screen and Video > Video Output

Review:

- Resolution
- 120 Hz Output
- VRR
- HDR
- Video Output Information

### Step 3 — Display Latency

Enable Game Mode on your television.

Disable unnecessary image interpolation and post-processing.

Use an appropriate HDMI port and cable for the supported display mode.

### Step 4 — Network Stability

For Remote Play:

- Prefer Ethernet for the PS5
- Avoid congested Wi-Fi networks
- Keep upload and download speeds stable
- Limit competing network activity
- Adjust streaming quality if necessary

### Step 5 — Maintenance

Update PS5 system software and GTA VI.

Ensure sufficient console ventilation.

Restart the console if troubleshooting persistent system problems.

## ❓ FAQ

**Does this unlock 60 FPS?**

No. Console frame-rate limits are controlled by the game and platform.

**Is a modified console required?**

No.

**Can I optimize the PS5 without a PC?**

Yes. Most console configuration steps can be completed directly on PlayStation 5.

**Can network optimization improve gameplay?**
